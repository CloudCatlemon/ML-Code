# 普隆德拉掛機記

致敬 RO 仙境傳說的 2D 橫向自動掛機遊戲（楓之谷式多層平台）。單一 HTML 檔，不需安裝任何東西，直接用瀏覽器開啟 `index.html` 即可遊玩。

## 玩法
- 角色會自動找怪、跳上或跳下平台、攻擊、施放技能、喝藥水、撿取掉落物。
- 初心者 Job Lv 10 可轉職：劍士、魔法師、弓箭手、服事、盜賊、商人，每個職業有 2 個主動技能和 1 個被動技能。
- 6 張地圖：普隆德拉原野 → 斐揚森林 → 夢羅克沙漠 → 斐揚洞窟 → 格拉斯海姆古城 → 迷宮森林，每張地圖都會定時出現 MVP。
- 能力值（STR/AGI/VIT/INT/DEX/LUK）使用 RO 的配點費用公式，可手動或自動配點。
- 裝備精煉 +1～+10：+4 以內安全，之後失敗時精煉值歸零。
- 卡片冊：每種怪物都有卡片，效果永久生效，最多疊加 3 張。
- 可切換 x1 / x2 / x4 遊戲速度；進度存在瀏覽器 localStorage，離線期間以 50% 效率結算收益（最多 8 小時）。

## 鍵盤操作
| 按鍵 | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ | 跳躍；站在 NPC 旁是對話，站在傳送點上是進入 |
| ↓ | 從平台跳下 |
| Space / Alt | 跳躍 |
| Z / X / Ctrl | 普通攻擊（按住連續攻擊） |
| 1 2 3 | 施放主動技能 |
| S | 坐下休息（回復加快） |
| Enter | 對話／進入傳送點 |
| A | 切換自動戰鬥／手動操作 |

按任何移動或攻擊鍵會自動切到手動操作，按 A 或畫面上方的「自動戰鬥」按鈕恢復掛機。

## 城鎮
普隆德拉、伊斯魯得、吉芬、斐揚、夢羅克、艾爾貝塔。每個城鎮都有卡普拉職員（存記錄點、傳送）、道具商人、
裝備商人或精煉師，以及對應職業的轉職公會。地圖邊緣的傳送點和狩獵場相連，死亡後會在記錄點復活；
自動戰鬥中陣亡時，3 秒後會自動傳送回狩獵場。

## 自己加點
- 能力值：在「能力值」分頁取消勾選「自動配點」，就能按 + 自己分配。
- 技能：每升 1 級 Job Lv 得到 1 點技能點數；在「技能」分頁取消勾選「自動點技能」，就能按 + 自己分配，也可以重置。

## 使用官方素材
遊戲不附帶任何 RO 官方圖片。你可以把自己從 RO 客戶端取出的 PNG 放進 `assets/`，或在遊戲的「設定 → 素材」匯入，
就會取代內建手繪圖（怪物、職業、地圖背景）。做法與代號清單見 [`assets/README.md`](assets/README.md)。
`assets/.gitignore` 預設不讓圖片進 repo，避免把有版權的素材公開出去。
